Entry for the [make.fun "One Line" bounty](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a): a program that writes one funny line of text to `/output/entry.txt`.

## The line

> I bought noise-cancelling headphones to finally hear myself think. Turns out I don't.

85 characters — inside the 1–140 character gate, one self-contained joke with a turn at the end.

## Run

```sh
node main.ts
```

Requires Node 22 or later. It validates the line against the gate (1–140 characters, not only whitespace) and writes it to `/output/entry.txt`.
